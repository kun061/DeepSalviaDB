# DeepPPI weights

Download the [DeepPPI-D model repository](https://huggingface.co/wangkun0601/deepppi-d) into this directory. Its `D/` subdirectory must contain:

- `D/seed_42/best.weights.h5`
- `D/seed_43/best.weights.h5`
- `D/seed_44/best.weights.h5`

See `../../docs/model_assets.md` for repository revisions and SHA256 checksums. The published repository currently does not specify license metadata; check with the publisher before reusing the weights.
