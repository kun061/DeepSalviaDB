# SalviaBench test set

This directory contains `SalviaBench-Final-150.csv`, the 150-question test set with `Category`, `Question`, and `Answer` columns. The CSV is used for evaluation and is not required to run the SalviaChat API.

Other runtime data and databases are not committed to Git. See [model assets](../../docs/model_assets.md) for the benchmark checksum and external resource paths.
